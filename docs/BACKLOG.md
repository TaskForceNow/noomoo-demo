# Backlog

The only inventory of the project's work. Closed entries move to `BACKLOG-ARCHIVE.md`; nothing is deleted from here.

## Legend
- Category: `work` · `idea` · `decision` · `research`
- Type: `bug` · `feature` · `tech-debt` · `doc` · `infra`
- Decision: `inbox` · `accepted` · `rejected` · `deferred`

**The category sets the outcome:** work → the chain requirement→use case→feature→task · idea → proposal · decision → ADR or rule · research → report.

**Progress** (`not started` / `in progress` / `done`) **is not written by hand**: it is derived from closed tasks or from presented evidence (`Closed by evidence` / `Merged into`).
