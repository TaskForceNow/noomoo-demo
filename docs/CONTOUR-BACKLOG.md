# Contour backlog

Defects of the noomoo core and of the contour itself found in this project. They go here, not to `BACKLOG.md`: the project backlog carries only the project's own work. Entries are numbered `CB-NNN` and have the same form as project backlog entries. The agent files an entry only with `Decision: inbox` and names its `Source`. The owner moves entries to the core backlog. `npx noomoo contour-issue CB-NNN --yes` opens a GitHub issue for an entry: the number goes into the entry as a `- Issue: #N` line, and running it again does not open a new issue.
